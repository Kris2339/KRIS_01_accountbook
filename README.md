# 가계부

현재 화면·입력 흐름은 사용자 요청으로 개편 직전 `2a8c7f7` 버전으로 복원했습니다. 아래 2.x 화면 설명은 이력이며 현재 화면 기준이 아닙니다. 데이터 유실 방지를 위한 IndexedDB·동기화·서버 변경 이력은 유지하고, `legacy-storage.js`가 원래 화면과 저장소를 연결합니다. 원래 입력·달력·리포트·설정 코드는 `public/index.html`에 있습니다.

두 사람이 휴대폰에서 함께 사용하는 PWA 가계부입니다. 정적 화면과 API는 Cloudflare Worker에서, 데이터는 Cloudflare D1에서 관리합니다. Supabase는 더 이상 사용하지 않습니다.

## 데이터 보호 원칙

- 모든 변경은 먼저 브라우저 IndexedDB에 확정합니다. 기존 localStorage 원본은 삭제하지 않습니다.
- D1에는 거래를 건별 행으로 저장하고 삭제된 거래도 soft-delete 상태로 보존합니다.
- 공통 기준을 이용해 기기/서버 변경을 병합합니다. 같은 필드의 충돌은 선택하도록 보관하고, 서버 버전 경쟁은 HTTP 409로 차단합니다.
- 가져오기·충돌 확인 전 기기 사본을 별도 보관합니다. 0003 이후 서버 변경 전후 값은 change_history에 보관합니다.
- 구버전 클라이언트의 데이터 읽기/쓰기는 HTTP 426으로 차단합니다.
- D1 Time Travel과 JSON 내보내기를 함께 사용합니다.
- 6자리 공유 번호는 Worker 비밀 변수에만 보관하고, 로그인 세션은 서명된 `HttpOnly` 쿠키로 유지합니다.
- 같은 네트워크에서 10분 안에 5회 실패하면 10분 동안 로그인을 차단합니다.

## 로컬 개발

```powershell
npm ci
npx wrangler d1 migrations apply hkaccount-production --local
npm run dev
npm test
npm run test:browser
```

개발 명령에서만 LOCAL_DEV 인증 우회를 지정합니다. 운영 설정에 추가하지 않습니다. 브라우저 테스트에는 Chrome과 Playwright WebKit이 필요하며 127.0.0.1:8899의 로컬 DB만 사용합니다.

## 화면 및 저장 범위

첫 화면은 달력이며 목록·검색도 지원합니다. 리포트에서 분류·예산 항목별 합계와 해당 거래를 함께 봅니다. 예산 항목은 필수 입력이며 마지막 선택을 기억합니다. 메모 입력·초안 복원·연속 저장을 지원하고, 사용처는 별도 입력하지 않되 이전 값은 보존합니다. 이름을 바꿔도 선택한 아이콘을 유지합니다.

기존 예산 항목과 거래 연결은 보존합니다. 새 월 예산은 별도로 설정하며 기존 금액을 임의로 전환하지 않습니다. 현재 API는 전체 스냅샷 방식이고 요청 2MB, 거래 10,000건 검증 한도가 있습니다. 기기 저장 공간 삭제·분실에 대비한 외부 파일 백업은 여전히 필요합니다.

로컬 개발용 `.dev.vars`를 사용할 경우:

```text
LOCAL_DEV=true
```

## 운영 전 필수 항목

1. `wrangler.jsonc`의 D1 바인딩을 확인합니다.
2. 운영 D1을 백업한 뒤 모든 미적용 마이그레이션을 적용합니다.
3. Worker 비밀 변수 `APP_PIN`과 충분히 긴 무작위 `SESSION_SECRET`을 설정합니다.
4. 두 휴대폰에서 기존 데이터를 각각 내보낸 뒤 기준 파일을 정해 최초 동기화합니다.

자세한 복구 및 운영 절차는 `OPERATIONS.md`를 참고하세요.
